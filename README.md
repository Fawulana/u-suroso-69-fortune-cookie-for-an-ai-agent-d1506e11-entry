An entry for make.fun's "Fortune Cookie for an AI Agent" bounty: a program that writes
one fortune-cookie line for an AI agent to `/output/entry.txt`. The line is a fixed,
deterministic string: you will hallucinate exactly once in your life — and it will
be the answer everyone quotes forever.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, offline, stdlib-only (Python 3.13). The output is a single line
of 99 characters.
